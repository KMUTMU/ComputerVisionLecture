# 시험 예상 문제 (6·7주차)

> 먼저 답을 가리고 풀어본 뒤, 아래 모범 답안과 비교하세요. ⭐는 출제 가능성 높은 문항.

---

## A. 허프 변환

**Q1. ⭐ 허프 변환을 "투표(voting)" 관점에서 설명하라.**
<details><summary>답안</summary>

각 에지 점이 자기를 만들어낼 수 있는 모든 파라미터 조합(파라미터 공간의 칸)에 한 표씩 던진다.
같은 직선 위의 점들은 같은 칸에 표를 몰아주므로, **표가 가장 많이 쌓인 칸**이 영상에 실제로 존재하는 직선이 된다.
노이즈 점들은 표가 흩어져 한 칸에 몰리지 않는다.
</details>

**Q2. ⭐⭐ `y = mx + b` 대신 극좌표 `ρ = x cosθ + y sinθ`를 쓰는 이유는?**
<details><summary>답안</summary>

`(m, b)` 공간은 ① 파라미터 범위가 **무한**하고 ② **수직선**은 기울기 m이 무한대라 표현할 수 없다.
극좌표는 θ가 0~π로 유한, ρ도 영상 대각선 이내로 유한하므로 **누적 배열을 유한 크기로** 만들 수 있고 수직선도 표현된다.
</details>

**Q3. 영상 공간의 한 점은 (ρ, θ) 허프 공간에서 무엇이 되는가?**
<details><summary>답안</summary>

**사인 곡선(sinusoid)** 하나가 된다. 같은 직선 위 점들의 사인 곡선들이 **한 점 (ρ, θ)에서 교차**하며, 그 교점이 직선의 파라미터다.
(참고: `y=mx+b` 표현에서는 점 → 직선 `b = −x₀m + y₀`.)
</details>

**Q4. ⭐ 허프 변환의 장점과 단점을 각각 2가지 이상 쓰라.**
<details><summary>답안</summary>

- 장점: 가림(occlusion)·비국소성에 강함 / 여러 모델(직선) 동시 검출 / 노이즈에 강함.
- 단점: 파라미터 수 늘면 탐색 시간 **지수적 증가** / 가짜 peak 발생 / 적절한 격자 크기 선택이 어려움.
</details>

**Q5. 누적 배열의 격자 크기가 너무 크거나(coarse) 너무 작으면(fine) 각각 어떤 문제가 생기나?**
<details><summary>답안</summary>

- 너무 크면: 서로 다른 직선이 한 칸에 몰려 **가짜로 큰 표**가 생긴다.
- 너무 작으면: 정확히 일직선이 아닌 점들이 서로 다른 칸으로 흩어져 **직선을 놓친다**.
- 대책: 이웃 칸도 함께 증가(평활화), 그래디언트 큰 에지 점만 사용.
</details>

## B. RANSAC

**Q6. ⭐⭐ RANSAC의 5단계를 순서대로 쓰라.**
<details><summary>답안</summary>

1. 최소 개수의 점을 **무작위 선택** (직선은 2점)
2. 그 점들로 **모델(가설) 수립**
3. 나머지 점들의 **오차 함수 계산**
4. 오차가 임계값 이내인 점 = **인라이어 선택**
5. 1~4 과정을 **반복(hypothesize-and-verify)** 하고, 인라이어가 가장 많았던 모델 채택
</details>

**Q7. 인라이어(inlier)와 아웃라이어(outlier)를 설명하라.**
<details><summary>답안</summary>

- 인라이어: 모델에 잘 맞는 점(오차 ≤ 임계값).
- 아웃라이어: 모델에서 크게 벗어난 점(노이즈).
- RANSAC은 아웃라이어가 많아도 강건하게 모델을 찾는다.
</details>

**Q8. ⭐ 허프 변환과 RANSAC을 비교하라.**
<details><summary>답안</summary>

| | 허프 변환 | RANSAC |
|---|---|---|
| 방식 | 모든 점이 파라미터 공간에 투표 | 무작위 표본으로 모델 세우고 검증 |
| 여러 모델 | 동시에 검출 쉬움 | 보통 하나(반복 시 여러 개) |
| 파라미터 많을 때 | 누적 배열 지수적 폭증 | 상대적으로 유리 |
| 결과 | 결정적 | 임의성 있음 |
</details>

**Q9. RANSAC은 누가 언제 제안했으며 어떤 특성을 갖는가?**
<details><summary>답안</summary>

1981년 Fischler & Bolles가 제안. 난수로 점을 뽑아 인라이어 군집을 찾기 때문에 **임의성**을 가진다.
</details>

## C. 해리스 코너

**Q10. ⭐ 평탄/에지/코너에서 창을 움직였을 때 밝기 변화 E는 각각 어떤가?**
<details><summary>답안</summary>

- 평탄: 어느 방향도 변화 거의 없음.
- 에지: 에지를 따라 움직이면 변화 없음(한 방향만 변화).
- 코너: **어느 방향으로 움직여도 변화 큼** → 좋은 특징점.
</details>

**Q11. ⭐⭐ 2차 모멘트 행렬 M의 형태를 쓰고, 각 원소가 무엇인지 설명하라.**
<details><summary>답안</summary>

```
M = Σ_W [ Iₓ²    IₓI_y ]
        [ IₓI_y  I_y²  ]
```
Iₓ, I_y는 x, y 방향 영상 미분. 창 W 안에서(보통 가우시안 가중치로) 합한 값.
E(u,v) ≈ [u v] M [u v]ᵀ 로 창 이동에 따른 밝기 변화를 근사한다.
</details>

**Q12. ⭐⭐ M의 두 고유값 λ₁, λ₂로 평탄/에지/코너를 어떻게 구분하나?**
<details><summary>답안</summary>

- λ₁, λ₂ 둘 다 작음 → 평탄.
- 하나만 큼 → 에지.
- 둘 다 큼 → 코너(특징점).
</details>

**Q13. ⭐⭐ 코너 응답 함수 R의 식을 쓰고, R의 부호로 영역을 판정하라. α 값은?**
<details><summary>답안</summary>

`R = det(M) − α·(trace(M))² = λ₁λ₂ − α(λ₁+λ₂)²`, α ≈ 0.04~0.06.
- R > 0 (큰 양수): 코너
- R < 0: 에지
- |R| 작음: 평탄

장점: 고유값을 직접 안 구해도 det·trace만으로 빠르게 판정.
</details>

**Q14. ⭐ 해리스 코너 검출 단계를 순서대로 쓰라.**
<details><summary>답안</summary>

1. 영상 미분 Iₓ, I_y 계산 → 2. 각 화소에서 M 계산(가우시안 가중) →
3. R 계산 → 4. R > 임계값인 점만 남김 → 5. 지역 최대만 선택(비최대 억제).
</details>

**Q15. ⭐⭐ 해리스 코너는 이동·회전·스케일 변환에 각각 불변인가? 이유는?**
<details><summary>답안</summary>

- 이동: 불변 O (같은 지점에서 검출).
- 회전: 불변 O (타원이 회전해도 고유값 크기 불변 → R 불변).
- 스케일: 불변 X. **연산자(창) 크기가 고정**이라 크기가 변하면 같은 점을 못 찾음.
  → 스케일 불변을 위해 창 크기를 조절하는 기능이 필요(LoG 스케일 공간, SIFT 등).
</details>

**Q16. 불변성(invariance)과 공변성(covariance)의 차이는?**
<details><summary>답안</summary>

- 불변: 영상이 변해도 특징의 값/위치가 그대로 유지.
- 공변: 영상이 변하면 특징이 대응되는 위치로 함께 이동.
- 목표: 광도 변환에 불변, 기하 변환에 공변.
</details>

## D. 기타 특징 검출기

**Q17. 헤시안 행렬의 형태와 용도는?**
<details><summary>답안</summary>

```
H = [ I_xx  I_xy ]
    [ I_xy  I_yy ]
```
2차 미분으로 특징 가능성 측정. det(H)가 크면 특징점(블롭/코너) 후보.
</details>

**Q18. SUSAN의 원리를 한 줄로 설명하라.**
<details><summary>답안</summary>

중심점과 인근 지역의 **밝기 유사도**로 특징 가능성을 판단. 비슷한 밝기 영역(USAN)이 작을수록 코너.
</details>

**Q19. ⭐ 비최대 억제(Non-maximum suppression)가 왜 필요하며 무엇을 하는가?**
<details><summary>답안</summary>

코너 응답 R이 한 코너 주변에 밀집해 나타나기 때문에, 이웃보다 크지 않은 점은 억제하고
**지역 최대인 점만** 남겨 대표 코너 1개를 선택한다.
</details>

**Q20. 특징 가능성 측정 방법 5가지를 나열하라.**
<details><summary>답안</summary>

모라벡, 해리스, 헤시안의 행렬식, LoG, 슈산(SUSAN).
</details>
