# 6주차 — 선분 검출 (허프 변환 · RANSAC)

> 전체 흐름: **에지 맵 → 에지 토막 → 선분**
> 에지 검출로 얻은 점들 중에서 "일직선으로 늘어선 점들"을 찾아 **선분(line)** 으로 만드는 단계입니다.

---

## 0. 큰 그림: "투표(Voting)"라는 아이디어

선분/도형을 찾는 문제를 **투표**로 바꿔서 푸는 방법입니다.

- 각 특징점(에지 점)이 **자기와 맞는 모델(직선 등)에 한 표씩 던진다.**
- 노이즈 점들은 **제각각 다른 곳에 표를 던져서** 한 모델에 몰리지 않는다.
- 데이터 일부가 빠져도(occlusion/missing) **남은 점들만 충분하면** 모델을 찾을 수 있다.

> 💡 핵심: "많은 표를 받은 모델 = 진짜 있는 선분" 이라는 발상.
> 허프 변환(Hough Transform)이 이 투표 방식의 대표 예입니다.

---

## 1. 허프 변환 (Hough Transform)

### 1-1. 기본 개념
- 1959년 P.V.C. Hough가 제안한 **초기 투표 기법**.
- 절차:
  1. **파라미터 공간**을 칸(bin)으로 잘게 나눈다 (누적 배열 = accumulator).
  2. 영상의 **각 에지 점**에 대해, 그 점을 만들어낼 수 있는 **모든 칸에 한 표씩** 던진다.
  3. **표가 가장 많이 몰린 칸**을 찾는다 → 그 칸이 곧 검출된 직선.

### 1-2. 영상 공간 ↔ 허프 공간의 "쌍대성(duality)"

직선을 `y = mx + b`로 쓰면:

| 영상 공간 (image space) | 허프 공간 (parameter space) |
|---|---|
| 하나의 **직선** (m, b 고정) | 하나의 **점** (m, b) |
| 하나의 **점** (x₀, y₀) | 하나의 **직선** b = −x₀·m + y₀ |

- 영상의 한 점 (x₀, y₀)를 지나는 직선은 무수히 많다 → 허프 공간에서는 **직선 하나**가 된다.
- 두 점 (x₀,y₀), (x₁,y₁)를 **동시에** 지나는 직선은?
  → 허프 공간에서 두 직선 `b = −x₀m + y₀` 와 `b = −x₁m + y₁` 의 **교점**.
- 같은 직선 위의 점들이 던진 표는 허프 공간의 **한 교점에 몰린다** → 그 교점이 직선의 (m, b).

### 1-3. (m, b) 대신 (ρ, θ)를 쓰는 이유 ⭐ (시험 단골)

`y = mx + b` 방식의 문제점:
- **파라미터 범위가 무한**하다 (m, b가 ±∞까지).
- **수직선**은 기울기 m이 무한대라 표현 불가.

➡️ 해결: **극좌표(normal form)** 사용
```
ρ = x·cosθ + y·sinθ
```
- ρ: 원점에서 직선까지의 **수직 거리**
- θ: 그 수직선의 **각도** (0 ~ 180°)
- θ는 유한 범위(0~π), ρ도 유한(영상 대각선 길이 이내) → **누적 배열을 유한 크기로** 만들 수 있다.
- 영상의 한 점은 허프 공간 (ρ, θ)에서 **사인 곡선(sinusoid)** 하나가 된다.
- 같은 직선 위의 점들의 사인 곡선들이 **한 점(ρ, θ)에서 교차** → 그 점이 직선.

### 1-4. 노이즈 대처 (Dealing with noise)
- **격자(칸) 크기를 잘 고르기:**
  - 너무 크면(coarse): 서로 다른 직선들이 한 칸에 몰려 가짜 큰 표가 생김.
  - 너무 작으면(fine): 정확히 일직선이 아닌 점들이 서로 다른 칸에 흩어져 직선을 놓침.
- **이웃 칸도 함께 증가**시키기 (누적 배열 평활화/smoothing).
- **의미 없는 특징 제거**: 그래디언트 크기가 충분히 큰 에지 점만 사용.

### 1-5. 원(circle)에 대한 허프 변환
- 원은 파라미터가 3개 `(x, y, r)` → 3차원 누적 배열.
- 각 에지 점마다 가능한 `(x, y, r)` 조합에 투표.
- **파라미터가 늘수록 계산량이 기하급수적으로 증가**가 단점.

### 1-6. 허프 변환 장단점 ⭐ (시험 단골)

**장점(Pros)**
- 비국소성(non-locality)과 **가림(occlusion)** 에 강함.
- **여러 개의 모델(여러 직선)** 을 동시에 검출 가능.
- 노이즈에 어느 정도 강함 (노이즈는 한 칸에 일관되게 몰리기 어려움).

**단점(Cons)**
- 모델 파라미터 수가 늘면 **탐색 시간이 지수적으로 증가**.
- 목표가 아닌 모양이 **가짜 peak**를 만들 수 있음.
- **적절한 격자 크기**를 고르기 어려움.

## 2. Implicit Shape Model (ISM) — 투표의 물체 인식 응용

> 허프 변환의 "투표" 아이디어를 **물체 검출**로 확장한 예 (Leibe, Leonardis, Schiele, 2004).

### 학습(Training)
1. 관심점 주변 패치들을 모아 **코드북(codebook)** 을 클러스터링으로 구성.
2. 각 관심점 패치를 **가장 가까운 코드북 항목**에 대응시킴.
3. 각 코드북 항목마다, 그것이 발견된 위치를 **물체 중심 기준 상대 위치**로 저장.

### 추론/테스트(Testing)
1. 테스트 영상에서 패치 추출 → 코드북과 매칭.
2. **물체 중심의 가능한 위치**에 투표(vote).
3. 투표 공간에서 **극대(maxima)** 를 찾음.
4. 저장된 마스크로 **가중 분할(segmentation) 마스크** 추출.

### 세부 포인트
- 지도학습(각 학습 물체마다 기준 위치·분할 마스크 필요).
- 투표 공간은 **연속적** → 극대를 찾으려면 클러스터링 필요.
- 스케일 변화 대응: ① 여러 스케일 탐색 ② 특성 스케일(characteristic scale) 가진 관심점 사용.
- **검증(verification) 단계가 매우 중요**: 위치 가설을 세운 뒤 템플릿을 겹쳐 픽셀 단위 비교.

## 3. RANSAC (RANdom SAmple Consensus)

### 3-1. 개념
- 1981년 **Fischler & Bolles**가 제안.
- **인라이어(inlier)** 를 찾아 어떤 모델을 적합(fitting)시키는 기법.
- **난수로 점을 뽑아** 인라이어 군집을 찾으므로 **임의성(randomness)** 을 가짐.
- 선분 검출에 적용 시 모델은 직선 `y = ax + b`.

### 3-2. 절차 (5단계) ⭐⭐ (시험 핵심)

```
1. Randomly select minimal subset of points
   (모델을 정하는 데 필요한 최소 개수의 점을 무작위로 뽑는다. 직선=2점)
2. Hypothesize a model
   (뽑은 점들로 모델(직선)을 하나 세운다)
3. Compute error function
   (나머지 모든 점이 이 모델에서 얼마나 떨어졌는지 오차를 계산)
4. Select points consistent with model
   (오차가 임계값(threshold) 이내인 점 = 인라이어로 선택)
5. Repeat hypothesize-and-verify loop
   (1~4를 여러 번 반복, 인라이어가 가장 많았던 모델을 채택)
```

> 💡 한 줄 요약: **"무작위로 뽑고(sample) → 모델 세우고(hypothesize) → 맞는 점 세고(verify) → 제일 많은 걸 고른다"**

### 3-3. 핵심 용어
- **인라이어(inlier):** 모델에 잘 맞는 점 (오차 ≤ 임계값).
- **아웃라이어(outlier):** 모델에서 많이 벗어난 점 (노이즈).
- RANSAC은 **아웃라이어가 많아도** 강건(robust)하게 직선을 찾아낸다.

### 3-4. 매칭 문제로의 확장 (7.3.2)
- 두 영상 간 매칭 쌍 집합 `X = {(a₁,b₁), (a₂,b₂), …, (aₙ,bₙ)}` 을 처리하도록 확장.
- 3장의 직선 검출과 같은 원리(뽑고–맞춰보고–반복)를 매칭에 그대로 적용.

### 3-5. 허프 변환 vs RANSAC 비교 ⭐

| | 허프 변환 | RANSAC |
|---|---|---|
| 방식 | 모든 점이 파라미터 공간에 **투표** | 점을 **무작위로 뽑아** 모델 세우고 검증 |
| 여러 모델 | 동시에 여러 개 검출 쉬움 | 보통 하나씩 (반복하면 여러 개도 가능) |
| 파라미터 많으면 | 누적 배열이 커져 **지수적 폭증** | 상대적으로 유리 (최소 표본만 뽑음) |
| 결과 | 결정적(격자 고정 시) | **임의성** 있음 (매번 조금 다를 수 있음) |

## ✅ 6주차 한 장 요약

- **허프 변환** = "투표". 에지 점들이 파라미터 공간에 표를 던지고, 표 많은 곳이 직선.
  - `(m,b)`의 무한 범위·수직선 문제 → **`ρ = x cosθ + y sinθ`** (극좌표)로 해결.
  - 장점: occlusion·노이즈 강함, 여러 직선 동시 검출. 단점: 파라미터 늘면 느림, 격자 선택 어려움.
- **RANSAC** = "무작위 표본 → 모델 가설 → 인라이어 세기 → 반복". 아웃라이어에 강건.
  - 5단계 순서(뽑기→가설→오차→인라이어→반복) 꼭 외우기.
- **ISM** = 투표 아이디어를 물체 인식에 확장 (코드북 + 중심 투표 + 검증).
